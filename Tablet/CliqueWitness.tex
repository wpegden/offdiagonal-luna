\begin{definition}
For a loop-aware graph $G$ and an integer $s$, a clique witness of order $s$
is an injective map from $[s]$ to the vertex set of $G$ whose distinct image
vertices are adjacent.  The injectivity requirement makes the witness a set
of $s$ distinct vertices, while the adjacency requirement is imposed only on
distinct indices and therefore does not impose a loop condition.
\end{definition}
