\begin{definition}
For a loopless digraph $D$, a copy of the transitive tournament $T_s$ is an
injective map from $[s]$ into $V(D)$ for which the arc from the earlier image
to the later image exists for every pair of indices $i<j$.  The definition is
for a directed subgraph, so it does not require the absence of additional
backward arcs.
\end{definition}
