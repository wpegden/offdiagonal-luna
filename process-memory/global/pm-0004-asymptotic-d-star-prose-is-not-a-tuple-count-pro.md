The high-level DStarCounting proof that only asserts |V(G)| ~ q^t, |V(D*)| ~ q^(2t-1), generic popular/poor children, and an O_t(q log q) unmarked path does not establish the paper's forward-independent bound. A valid proof must use the ordered adjacent-pair construction, exact n and d, Delta <= 4*q^(2t-1), the W/U_r/Z_r marking double counts, explicit expander-mixing and Alon-Rodl hypotheses, the dimension-decrease inequality, and the exact Nat.log threshold before applying RootedTreeCounting. This is the structural reason the current DStarCounting soundness verdict is rejected, as required by paper/new.tex:553-623.
